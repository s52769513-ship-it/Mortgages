# קבצי המותג

**הלוגו במערכת אינו תמונה.** הוא מצויר כצורות וקטוריות בתוך
`src/components/Logo.tsx`, ישירות בקוד העמוד.

הסיבה: מסנן תוכן ברשת (נטפרי) מטשטש תמונות לפני שהדפדפן מקבל אותן, ולכן
לוגו שנטען כקובץ תמונה הופיע מטושטש. צורות בתוך העמוד אינן בקשת תמונה, אז
אין מה לסנן. בונוס: הלוגו נשאר חד בכל גודל, ומקבל צבע לבן בסרגל הכהה בלי
קובץ נפרד.

## הקבצים כאן

| קובץ | תפקיד |
|---|---|
| `logo-source.png` | הקובץ המקורי שהועלה. ממנו נגזרו הצורות. |
| `favicon.svg` | האייקון בלשונית הדפדפן |
| `favicon.png` | גיבוי לדפדפנים ישנים שאינם תומכים ב-SVG |

## החלפת הלוגו

אם יש לך את הלוגו כ-SVG מקורי (מהמעצב) — הוא עדיף על ההמרה שנעשתה כאן,
כי הוא הצורות המקוריות ולא שחזור מתמונה. העלה אותו לתיקייה הזו ותגיד לי,
ואטמיע אותו במקום.

להחלפה ידנית: הצורות נמצאות בקבועים `NAVY` ו-`GOLD` בקומפוננטה, ומשתמשות
במערכת קואורדינטות הפוכה בציר Y (`translate(0,858) scale(0.1,-0.1)`).
