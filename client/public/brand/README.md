# קבצי המותג

**הלוגו במערכת אינו תמונה.** הוא מצויר כצורות וקטוריות בתוך
`src/components/Logo.tsx`, ישירות בקוד העמוד.

הסיבה: מסנן תוכן ברשת (נטפרי) מטשטש תמונות לפני שהדפדפן מקבל אותן, ולכן
לוגו שנטען כקובץ תמונה הופיע מטושטש. צורות בתוך העמוד אינן בקשת תמונה, אז
אין מה לסנן. בונוס: הלוגו נשאר חד בכל גודל, ומקבל צבע לבן בסרגל הכהה בלי
קובץ נפרד.

## הקבצים כאן

| קובץ | תפקיד |
|---|---|
| `logo-source.svg` | הלוגו המלא. **ממנו נלקחו הצורות שבקוד.** |
| `mark-source.svg` | הסמל בלבד. משמש בסרגל כשהוא מכווץ. |
| `logo-source.png` | הקובץ הראסטרי המקורי, לפני ההמרה |
| `mark-source.png` | הסמל בלבד, ראסטר |
| `favicon.svg` | האייקון בלשונית הדפדפן |
| `favicon.png` | גיבוי לדפדפנים ישנים |

## החלפת הלוגו

יש לוגו חדש? העלה אותו לכאן ותגיד לי — אני מחלץ את הצורות ומעדכן את
הקומפוננטה. אין להסתפק בהחלפת הקובץ: הקוד לא קורא אותו בזמן ריצה.

בקומפוננטה שלושה קבועים: `WORDMARK` (השם), `MARK_IN_LOGO` (הסמל בתוך
הלוגו המלא) ו-`MARK` (הסמל הבודד).
