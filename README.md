# מערכת ניהול משכנתאות

מערכת ניהול לסוכנות משכנתאות: לקוחות ולידים, תיקי משכנתא, משימות, מסמכים
ובקשות לבנקים — עם צ׳אט פנימי ויומן פעילות על כל ישות.

## מבנה

```
server/   Node + Express + TypeScript + Prisma (PostgreSQL)
client/   React + TypeScript + Vite + Tailwind (עברית, RTL)
```

## הרצה מקומית

נדרש Node 20+ ומסד PostgreSQL.

```bash
npm install

cp server/.env.example server/.env      # ואז לעדכן את DATABASE_URL ו-JWT_SECRET
npm run db:push --workspace=server      # יצירת הסכימה
npm run db:seed --workspace=server      # נתוני התחלה

npm run dev                             # API על 4000, ממשק על 5173
```

משתמש ראשוני מהזריעה: `admin@mortgages.local` / `Admin12345`.

## העלאה ל-Railway

שירות אחד מגיש גם את ה-API וגם את הממשק, כך שיש כתובת אחת ובלי CORS.

1. בפרויקט ב-Railway: **New → GitHub Repo**, ולבחור את הריפו ואת הברנץ'.
2. ב-**Variables** של השירות להוסיף:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (הפניה לשירות ה-Postgres)
   - `JWT_SECRET` = מחרוזת אקראית ארוכה
   - `NODE_ENV` = `production`
3. `railway.json` כבר מגדיר את הבנייה וההרצה. בכל דיפלוי רצה
   `prisma migrate deploy`, כך שהסכימה מתעדכנת לבד.
4. ב-**Settings → Networking** ללחוץ **Generate Domain** כדי לקבל כתובת.
5. ליצירת המשתמש הראשון, להוסיף גם `ADMIN_EMAIL` ו-`ADMIN_PASSWORD`. בעלייה
   הראשונה שבה טבלת העובדים ריקה ייווצר מהם מנהל מערכת; אחרי שנכנסים ומחליפים
   סיסמה אפשר למחוק את שני המשתנים. כל עוד קיים ולו עובד אחד, המנגנון לא עושה
   כלום — הוא לא ידרוס חשבון קיים ולא יחזיר חשבון שנמחק.

## רשימת הבנקים והסניפים

הבנקים והסניפים נטענים מהמאגר הפתוח של data.gov.il, כך שהבחירה בטופס נשענת על
הרשימה הרשמית ולא על רשימה שהוקלדה ידנית.

להרצה — אחת מהשתיים:

```bash
npm run import:banks                  # משורת הפקודה
POST /api/banks/import                # מתוך המערכת, למנהל מערכת בלבד
```

הפעולה בטוחה לחזרה: רשומות קיימות מתעדכנות ושום דבר שהוזן ידנית לא נמחק. שמות
העמודות במאגר השתנו בעבר, ולכן הקוד מזהה כמה כתיבים אפשריים לכל שדה במקום
להסתמך על אחד.

**בנקאים לא מגיעים משום מאגר** — הם אנשי קשר אישיים. שם שמוקלד בטופס נשמר
ומופיע בבחירה בפעם הבאה, וכך ספר הקשרים של המשרד נבנה מעצמו.

## מודל הנתונים

12 ישויות: `Employee`, `Client`, `MortgageFile`, `Task`, `Document`, `Bank`
(עם `BankBranch` ו-`Banker`), `BankApplication`, `ExternalProfessional`,
`Communication`, `OfficeExpense`, `Reminder`, ובנוסף שתי טבלאות רוחביות:

- **`Comment`** — הצ׳אט הפנימי. פונה לכל ישות דרך `entityType` + `entityId`,
  ולכן אותו רכיב משמש בכרטיס לקוח, בתיק, במשימה, במסמך ובבקשה לבנק.
- **`ActivityLog`** — יומן פעילות שנרשם אוטומטית, כולל מי ביצע, מתי, ומה היה
  הערך לפני ואחרי.

### שלבי התיק

התיק נע בשישה שלבים, והם מה שהסטפר מציג:
`היכרות → איסוף מסמכים → בקשה לבנק → אישור עקרוני → בטחונות → ביצוע ותשלום`.

### סטטוסים

הנתונים שומרים את מלוא הפירוט — עשרה סטטוסי משימה, תשעה סטטוסי מסמך — אבל
התצוגה מקבצת אותם לארבעה מצבים בלבד: **הושלם / בטיפול / ממתין / דחוף**. המיפוי
נמצא ב-`client/src/lib/labels.ts`, והוא המקום היחיד שבו נקבעות התוויות בעברית.

## שכבת העיצוב

הטוקנים ב-`client/src/styles/index.css` ו-`client/tailwind.config.js` מתורגמים
ממפרט הנראות: פלטת פלדה על רקע `#f2f2f3`, ארבעה צבעי מצב, סקאלת רדיוסים
(6 / 10 / 16 / 20), שלוש מהירויות תנועה (120 / 180 / 220ms) ועקומה אחת.

כללים שנשמרים לאורך הממשק:

- צבע לעולם לא לבד — לכל תג יש מילה, ולכל שורת טבלה קו סטטוס בקצה.
- כפתור ראשי אחד למסך.
- לכל שדה תווית קבועה, ושגיאה מוצגת כטקסט מתחתיו ולא רק כמסגרת אדומה.
- מיקוד מקלדת גלוי בכל אלמנט, ו-`prefers-reduced-motion` מכבה תנועה.
- מספרים, סכומים ותאריכים בכיוון לטיני כדי שלא יתהפכו ב-RTL.

## מה קיים ומה עוד לא

**קיים:** התחברות והרשאות, לקוחות ותיקים (CRUD מלא), דאשבורד, דף התיק על כל
לשוניותיו, שלושת מסכי הרשימה החוצה־תיקים (משימות, מסמכים, בקשות לבנק), חלונית
עריכת משימה, צ׳אט פנימי ויומן פעילות.

**בהמשך:** העלאת קבצים בפועל, תזכורות והסלמות, שילוב מייל, וסיווג מסמכים
אוטומטי.

### כללים שהשרת אוכף

- סטטוס המתנה במשימה מחייב לציין את הגורם שממתינים לו, וסגירת משימה מנקה אותו
  וחותמת את מועד הסיום.
- בנק, סניף ובנקאי נקלטים כטקסט חופשי ונוצרים בשימוש הראשון, כך שספר הקשרים של
  המשרד נבנה מעצמו.
- החלפת מסמך פותחת גרסה חדשה ומחזירה אותו לבדיקה, במקום לדרוס את הקודמת.
