# מערכת ניהול משכנתאות

מערכת ניהול לסוכנות משכנתאות: לקוחות ולידים, תיקי משכנתא, משימות, מסמכים
ובקשות לבנקים — עם צ׳אט פנימי ויומן פעילות על כל ישות.

## מבנה

```
server/   Node + Express + TypeScript + Prisma (PostgreSQL)
client/   React + TypeScript + Vite + Tailwind (עברית, RTL)
```

## הרצה מקומית

נדרש Node 20+ ומסד PostgreSQL.

```bash
npm install

cp server/.env.example server/.env      # ואז לעדכן את DATABASE_URL ו-JWT_SECRET
npm run db:push --workspace=server      # יצירת הסכימה
npm run db:seed --workspace=server      # נתוני התחלה

npm run dev                             # API על 4000, ממשק על 5173
```

משתמש ראשוני מהזריעה: `admin@mortgages.local` / `Admin12345`.

## מודל הנתונים

12 ישויות: `Employee`, `Client`, `MortgageFile`, `Task`, `Document`, `Bank`
(עם `BankBranch` ו-`Banker`), `BankApplication`, `ExternalProfessional`,
`Communication`, `OfficeExpense`, `Reminder`, ובנוסף שתי טבלאות רוחביות:

- **`Comment`** — הצ׳אט הפנימי. פונה לכל ישות דרך `entityType` + `entityId`,
  ולכן אותו רכיב משמש בכרטיס לקוח, בתיק, במשימה, במסמך ובבקשה לבנק.
- **`ActivityLog`** — יומן פעילות שנרשם אוטומטית, כולל מי ביצע, מתי, ומה היה
  הערך לפני ואחרי.

### שלבי התיק

התיק נע בשישה שלבים, והם מה שהסטפר מציג:
`היכרות → איסוף מסמכים → בקשה לבנק → אישור עקרוני → בטחונות → ביצוע ותשלום`.

### סטטוסים

הנתונים שומרים את מלוא הפירוט — עשרה סטטוסי משימה, תשעה סטטוסי מסמך — אבל
התצוגה מקבצת אותם לארבעה מצבים בלבד: **הושלם / בטיפול / ממתין / דחוף**. המיפוי
נמצא ב-`client/src/lib/labels.ts`, והוא המקום היחיד שבו נקבעות התוויות בעברית.

## שכבת העיצוב

הטוקנים ב-`client/src/styles/index.css` ו-`client/tailwind.config.js` מתורגמים
ממפרט הנראות: פלטת פלדה על רקע `#f2f2f3`, ארבעה צבעי מצב, סקאלת רדיוסים
(6 / 10 / 16 / 20), שלוש מהירויות תנועה (120 / 180 / 220ms) ועקומה אחת.

כללים שנשמרים לאורך הממשק:

- צבע לעולם לא לבד — לכל תג יש מילה, ולכל שורת טבלה קו סטטוס בקצה.
- כפתור ראשי אחד למסך.
- לכל שדה תווית קבועה, ושגיאה מוצגת כטקסט מתחתיו ולא רק כמסגרת אדומה.
- מיקוד מקלדת גלוי בכל אלמנט, ו-`prefers-reduced-motion` מכבה תנועה.
- מספרים, סכומים ותאריכים בכיוון לטיני כדי שלא יתהפכו ב-RTL.

## מה קיים ומה עוד לא

**קיים:** התחברות והרשאות, לקוחות ותיקים (CRUD מלא), דאשבורד, דף התיק על כל
לשוניותיו, צ׳אט פנימי ויומן פעילות.

**בהמשך:** מסכי הרשימה החוצה־תיקים למשימות, מסמכים ובקשות לבנק; העלאת קבצים;
תזכורות והסלמות; שילוב מייל; סיווג מסמכים אוטומטי.
